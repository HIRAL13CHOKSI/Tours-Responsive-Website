# Natours | Responsive Travel Website

A static travel landing page built with HTML, CSS, and JavaScript. It uses responsive layouts and a collapsible navigation menu for smaller screens.

## Preview locally

Open [`index.html`](index.html) in a browser. No build step or package installation is required. An internet connection is needed for externally hosted icons and images. Resize the browser to see how the navigation changes on mobile.

## Repository structure

- [`index.html`](index.html): page markup, inline styles, and navigation behavior.
- [`resources/`](resources/) and [`vendores/`](vendores/): supporting assets.
